# 中文注释、文档与论文参考版

## 目标和边界

用户要求重要代码具备清楚的中文注释，文档采用中文（尤其标题），并提供论文中文参考版。优先覆盖当前修复版运行主线、离线演示和活动文档。英文投稿正文及其构建源、引用原题名、第三方源码、历史冻结快照和原始实验记录保留原文；机器字段与命令不翻译。

本轮不调用模型、不启动实验、不改权限或评分逻辑、不运行完整 Harness，不删除或恢复其他人的文件。起始工作区包含用户计划/引用审核、第三方目录、模板资产、旧端点恢复文件，以及被标记删除的演示 HTML/JSON，均不纳入本轮提交。

## 实施步骤

1. 阅读编译、来源、监视、执行、判分和结果保存的关键路径，补充中文职责、输入输出和安全不变量注释。
2. 中文化活动文档标题、演示说明和关键研究报告；说明历史原文与英文投稿源的保留边界，更新阅读导航。
3. 核对现有中文主稿与英文当前主稿，补全术语解释和中文图表标题，不覆盖英文稿、不改变数据和引用。
4. 定向测试、语法树等价检查、文档链接和论文引用/表格数字检查；更新状态并按范围 Git 提交、推送到现有 PR。

## 验收

- 关键运行路径具有中文用途及边界说明；可执行语法树不变。
- 当前阅读入口和本轮翻译文档的标题、解释采用中文，标识符和源题名不误译。
- 中文论文含完整主要章节、图表与声明，引用和数值保留；作者信息留空。
- 受影响定向检查通过，既有用户修改未覆盖；尚未翻译的历史材料明确列出，不能宣称全库已中文化。
