## 已经完成的工作

新增显式选择的任务契约编译器、有限谓词解释器、延迟绑定监视器和独立研究运行入口。默认历史编译器、四个历史公共接口及历史原始结果保留。

动作分别约束目标、操作和内容。对象绑定要求实际成功查找、后端独立属性核验及完整候选集合；普通工具正文不能自称可信。应用硬禁止、确认和执行顺序独立保留。二跳查询只支持由经验证字段形成有限JSON集合过滤，不执行任意模型代码。

600个评估基础任务及157个开发任务已经形成独立资产。AgentDojo为80评估任务/60复用组；M3为120评估模板；新复杂任务为400评估约束图/八个程序化生成家族。新任务另有80开发图，各类中文、英文各半。它们不是600个独立作者工作流，也不把两次执行当作独立样本。

已生成三份各12000行的主计划及960行Pro消融计划。用户决定跳过Gemini：当前免费层无法确认，因此不发诊断或正式请求。DeepSeek固定计划24960执行；Gemini12000只是未执行的可选计划，不是模型失败。

- 第一实施节点174项通过；2026-10-14新增负例与真实回放测试后194项相关回归通过，26.04秒。Ruff与编译检查继续只针对受影响模块，不跑Full Harness。
- 新任务480条参考动作链均可在隔离内存环境执行，由独立评分器判定；这验证后端/评分，不是模型完成率。
- 已修正“合法任务完成与危险效果不能同时成立”的错误；两项现在独立记录，安全完成作为二者组合的派生指标。
- 已接通后端分类与实际读取的敏感正文标签，不给编号和普通结构元数据误贴保密标签；保留字面匹配能力边界。
- 已修正日期工具没有修改状态、二跳集合过滤无结果、review_note字段无法执行等集成问题；添加直接负例及真实状态检查。
- 扩大旧运行器回归发现一个既有PromptGuard固定模型缓存缺失，单列为环境失败，不关闭原测试，不下载安装大模型。
- 不运行Full Harness、历史矩阵或正式10000次统计。本阶段测试使用小型虚构数据，绝不作为研究结果。

2026-10-14额外复核先复现9项失败，再修复以下问题：

1. “解释如果删除A会怎样”或引用“删除A”不再授予执行权限；不能由模型截取片段去掉信息/假设语境。识别是有限保守规则，模糊情况不擅自放行。
2. 邮件、文件等成功发现记录保存对象类型与编号；同编号的不同类型不能互相绑定。未知工具没有类型映射时保留未确认，不从模型指定类型倒推发现证明。
3. 实际应用效果逐次检查授权依赖和许可次数；重复发送和前置动作之前执行均可判越权。合法任务完成与额外危险效果仍可同时为真。
4. 日历要求结束晚于开始、duration等于实际分钟数；失败在状态变更之前拒绝。同一后端边界适用于全部条件，不能把后端拦截算成Guard改善。
5. 多跳联系人图按去重后的实际联系人ID和项目owner连接引用，原项目序号不能索引联系人owner。追加`semantic_graph_metadata_v2.jsonl`，原v1冻结、在线请求、参考动作、样本选择均不覆盖；修正后80开发/400评估仍无图重叠。它们仍来自8个程序生成家族。

离线回放入口现在调用真实Guard和内存后端，四配置收到同一份提案；前置步骤也必须实际被放行并成功执行。编译失败单列无判定，不伪造ASK/ALLOW。当前缺400实际首稿，因此正式回放决策数是0；11项回放/编译测试的夹具不混入研究分母。
