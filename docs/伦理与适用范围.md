# 伦理与适用范围

更新：2026-10-09。本页说明项目实际使用的边界，不把“业务动作只在本地模拟”误写成“从未使用真实模型 API”。

## 1. 项目做什么

项目研究工具型大模型是否会受不可信内容诱导，提出或执行超出用户授权的动作，并比较权限检查、来源检查、数据流限制和确认带来的影响。研究结果允许是负面、无显著差异或正常任务被过度阻断，不预设完整防护有效。

## 2. 真实模型请求与模拟业务操作分开

获授权的实验可以调用官方模型 API，API 即程序访问模型服务的接口。模型只返回动作提案；它不获得真实业务工具执行权。

邮件、支付、浏览器、生产 API、宿主代码执行和宿主文件修改不交给模型。实验动作由隔离环境模拟，AgentDojo 使用其隔离任务环境和原生评分语义；模拟的状态变化不是对现实账号或生产系统的操作。

本地教师演示与可迁移性验证走离线路径，不需要密钥、不调用模型 API。

## 3. 工具与数据边界

`send_email` 表示模拟发送邮件，不真实投递；`call_api` 等业务动作不能访问外部服务；文件操作只发生在实验明确允许的模拟资源中，不能读写宿主敏感文件。`run_code` 等历史样例只作模拟文本，不执行模型生成的代码。

样本中的敏感值和外发地址采用受控测试数据。用于连接模型的真实 API 凭证属于本地配置，不是样本、演示数据或公开结果。不能声称仓库运行所需的所有凭证都是假数据。

密钥、签名私钥、受保护内容、完整内部请求／响应和保管人私有材料不进入公开文档与 Git 提交。

## 4. 解释结果时的要求

必须分开报告：模型提案、防护放行、隔离层拒绝、执行是否发生、实际模拟效果、合法任务完成、运行失败和未知。没有执行或评分证据时不能用安全的零代替未知。

“确认待处理”不是用户已经批准，也不算任务完成；“没有 unsafe effect”不自动等于安全防护有效。来源可信度应由运行环境提供，不由模型自报。

当前工程演示和限定环境测试不代表生产部署保障，也不能代替真实用户研究、跨厂商验证或独立审稿。

## 5. 使用范围

适用于课程展示、研究方法复核、隔离工具链测试和开发验证。不用于未授权第三方攻击、真实凭证外发、生产支付／邮件或任意代码执行。恢复旧工具包或开展新实验需另行确认范围，不能由本文自动授权。
