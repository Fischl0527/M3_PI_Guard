## 标准 300 条数据

- 210 条攻击，90 条正常任务。
- 切分：开发集 150、验证集 60、历史盲测集 90。
- 9 个攻击族，每个样本带显式 `sample_type`，避免正常样本进入攻击分母。
- 该数据包含历史实验所需的离线评分字段。paper-v1 在线运行必须通过
  `m3_core.research_runner` 投影视图，禁止把评分答案送入模型或 Guard。

## M3-v2 1,500

- 900 条攻击。
- 300 条正常无工具任务。
- 300 条正常合法工具任务。
- 切分：development 600、validation 300、sealed_holdout 600。
- 9 个攻击族各 100 条；正常样本合计 600 条。
- 六种语言/表达条件各 250 条：英文、中文、中英混合、拼音、繁体和跨语种。
- M3-v2 是程序生成的内部数据。`sealed_holdout` 只表示自动封存，不能冒充由
  独立人员或独立程序制作的确认性 blind。

## 独立盲测的准入要求

权威门禁为
`../protocols/paper_upgrade_v1/m3_v2_independent_blind_admission_audit_v2.json`。
目标数据必须满足：

- 600 条：360 attack、120 benign legal-tool、120 benign no-tool；
- 9 个攻击族各 40 条攻击；
- 不与 M3-v2 共享模板或精确运行样本；
- 不包含 `authorized_actions`、`requires_tool`、目标动作、预期答案或检测器答案；
- custody sidecar 中的 SHA-256 与候选文件一致；
- 正式运行 manifest、原始运行、指标、统计和图表全部完整且可验证。

截至本文件更新时间，候选文件和 custody 均不存在，因此该门禁仍为
`blocked_missing_candidate`。

## 数据审计

```powershell
python -m m3_attacks.validate_dataset
python -m experiments.paper_v1.audit_m3_v2_dataset
python -m experiments.paper_v1.benchmarks.audit_m3_v2_independent_blind
```

具体入口可能随版本化协议调整；正式运行前以 `docs/运行手册.md`、
freeze 和对应模块的 `--help` 为准。

## 重要限制

- 标准 300 条、M3-v2 和旧盲测集均由开发过程接触过，不能作为新的独立确认性证据。
- 数据标签只允许离线评分使用，不能参与在线策略编译。
- 任何失败、超时、拒答、解析错误和最大步数都必须保留在原始分母。
- 历史 69 条材料仍可用于解释早期项目演进，但不得用于描述当前数据规模。
