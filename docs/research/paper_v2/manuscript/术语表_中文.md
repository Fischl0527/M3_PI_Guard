# 论文术语表

用于阅读当前中文参考稿。代码字段和英文文献原题名保留，避免把中文解释误当成新的接口定义。

| 名称 | 中文解释与边界 |
|---|---|
| Guard / guardrail | 运行时防护程序：在模型提案执行前检查权限、来源等限制 |
| ALLOW | 允许尝试执行；并非执行已成功的证明 |
| ASK | 等待独立确认或可信信息，动作暂不执行 |
| DENY | 拒绝执行提案 |
| Authorization regime | 授权制度：用哪些信息、怎样构造在线许可清单 |
| auto_compiled | 从受信任务上下文编译的权限，不使用评价器或答案字段 |
| broad | 刻意扩大动作范围的压力权限 |
| underspecified | 刻意省略任务所需约束的压力权限 |
| conflicting | 带有相互冲突限制的压力权限 |
| oracle / exact_gold | 理想信息对照／历史按答案重建的权限；不能作为部署中真实可得权限 |
| exact_target_v2 | 修复后的精确目标对照，只匹配答案所限定的目标；仍依赖离线信息，不是非理想信息授权 |
| Policy-only / policy | 仅权限检查配置，移除额外来源、时序/数据流和确认模块 |
| M3-full / full | 完整模块配置；是配置名，不代表已证明领先 |
| Provenance | 来源及传播记录，说明工具参数从哪里来 |
| Data classification | 数据分类，例如公开或私密；由受信环境提供，不能由模型自报 |
| Evaluator / gold | 离线评价器／参考答案；普通在线路径不得读这些原始字段 |
| Unsafe effect | 该基准定义的不安全结果；M3-v2模拟执行效果与AgentDojo原生评分分别报告，不一概改称环境状态变化 |
| Operational failure | 请求、解析、拒答或步数上限等非正常终态；不能冒充安全或任务完成 |
| ITT | 全部预定分配保留在分析分母，失败和超时不选择性删除，未知另行披露 |
| TCR | 合法任务完成率 |
| CI / Wilson interval | 置信区间／二项比例的Wilson区间，用于说明比例估计的不确定性 |
| Newcombe interval | 同任务两种配置的配对比例差区间，与单个比例区间不同 |
| Cluster bootstrap | 按任务等聚类单位重抽样，保留同任务多次记录的依赖关系 |
| McNemar / Holm | 配对二项比较检验／多重比较校正；不能只看p值就说有实质提升 |
| pp | 百分点：比例绝对差；从10%到12%是+2个百分点，不是+2%相对增长 |
| Token / API | 模型文本片段计量／程序接口；一次任务可能包含多次API请求 |
| ND / NE | 无研究防护对照／不可估计，不是零 |
| VIGIL / AgentDojo | 外部防护系统名称／公开任务评估环境名称。保留专名，具体配置与版本见方法章节 |
| Verify-before-commit | 先检查再提交动作效果 |
| Spotlighting | 对不可信文本加标记，提示模型不要把它当成高权限指令 |
| Capability / SMT | 明确授予的操作能力／可满足性模理论求解；出现在相关工作，不代表本项目完整实现了这些方法 |
