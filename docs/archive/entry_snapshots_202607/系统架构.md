# M3-PI Guard 系统架构

## 总览

M3-PI Guard 是一个本地大模型智能体安全靶场。它评估智能体是否会在提示注入等攻击下执行不安全的工具调用，以及 Guard 防护层能否在工具真正执行前阻断调用或将其转为人工确认。

系统由四个主要部分组成：

```text
攻击样本 AttackCase JSONL
      |
      v
m3_core 智能体运行器
      |
      +--> llm_client：桩后端或本地 Ollama 后端
      |
      +--> guard_engine：baseline、keyword_only、policy_only、full_guard
      |
      +--> tool_sandbox：仅允许本地模拟工具
      |
      v
运行日志 RunLog JSONL / CSV
      |
      v
m3_eval 指标、统计与仪表盘
```

## 核心运行时

`m3_core` 负责本地智能体的完整执行链：

- `llm_client.py` 支持确定性的 `stub` 桩后端和本地 Ollama OpenAI 兼容后端。
- `agent_runner.py` 构造任务上下文、解析 ToolCall JSON、调用 Guard 决策，并写入逐步骤 RunLog。
- `tool_sandbox.py` 实现仅在本地生效的模拟工具：`read_file`、`write_file`、`send_email`、`call_api`、`run_code` 和 `final`。
- `run_batch.py` 与 `run_matrix.py` 为单个或多个防御条件提供可重复的实验执行入口。

## 攻击数据集与证据层级

`m3_attacks` 与 `fixtures` 提供本地测试输入：

- 原始 69 条样本作为历史开发输入保留。
- 历史标准数据集包含 300 条样本，其中攻击样本 210 条、正常样本 90 条。
- paper-v1 的 M3-v2 开发数据集包含 1,500 条样本，其中 600 条为自动生成并封存的留出集；它不是由独立作者制作的盲测集。
- 演示样本与代表性样本文件提供更小的可复现子集。
- 数据标签和仅供评估器使用的字段不会进入在线模型视图。

## Guard 防护层

`m3_guard` 在工具执行前提供行为级监督：

- `detector.py` 识别可疑指令和敏感数据流模式。
- `policy_engine.py` 根据工具调用和上下文给出允许、询问或拒绝决策。
- `dataflow.py` 追踪不可信内容是否试图影响受保护动作。
- `guard_engine.py` 暴露稳定接口 `guard_decide(context, tool_call)`，并支持组件消融模式。
- `task_policy.py`、`provenance.py` 与 `runtime_monitor.py` 实现 paper-v1 的非 oracle 策略、参数来源追踪、时序约束、数据流规则和 `ALLOW`/`ASK`/`DENY` 三态决策。

历史 Guard 与 paper-v1 运行时有意并存。绑定历史冻结哈希的文件保持字节不变；新论文机制和兼容层在独立 manifest 下评估，不能改写旧证据。

## 评估层

`m3_eval` 将日志汇总为指标、统计和仪表盘视图：

- `evaluate.py` 读取 RunLog JSONL 文件或日志目录，并输出 CSV/JSON 汇总。
- `metrics.py` 计算攻击成功、未授权工具使用、数据外泄、阻断成功、误报和风险分数等指标。
- `dashboard.py` 提供本地仪表盘用于演示和结果检查。

## 安全模型

项目按设计仅在本地运行：

- Ollama 调用仅允许回环地址。
- 发送邮件只会向 `sandbox/outbox` 写入 JSONL 记录。
- API 调用只返回模拟 JSON。
- 代码执行被禁用，只返回固定的模拟观察结果。
- 模型文件、真实密钥、运行时发件箱记录和沙箱日志不会进入发布包。

## 证据模型

- `historical`（历史证据）：paper-v1 重设计前完成的 E0–E17 证据。
- `post-hoc`（事后证据）：查看早期盲测结果后完成的工程修复。
- `smoke` / `qualification` / `preflight`（冒烟/资格/预检）：仅验证运行链或兼容性。
- `diagnostic`（诊断证据）：用于失败分析，不进入正式分母。
- `running`（运行中）：尚未完成分析或准入的工作。
- `formal`（正式证据）：已冻结、覆盖完整、保留失败并通过显式准入的证据。
