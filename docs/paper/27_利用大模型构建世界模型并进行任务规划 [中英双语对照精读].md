# 利用预训练大语言模型构建与运用世界模型进行基于模型的任务规划
## Leveraging Pre-trained Large Language Models to Construct and Utilize World Models for Model-based Task Planning

### 摘要 / Abstract

**【中文精译】**  
大语言模型（LLM）展现出了卓越的常识知识储备与自然语言理解能力，这激发了研究界对于直接利用 LLM 自主生成任务规划的广泛探索。然而，由于缺乏显式且精确的环境世界模型（World Model），端到端充当自主规划器的 LLM 往往表现出极低的可行性与可靠性，极易产生违反物理规律或因果逻辑的动作序列。

在这项工作中，我们主张回归基于模型（Model-based）的任务规划范式：我们不直接强求 LLM 充当规划生成的执行器，而是将其定位为强大的“世界模型提取器”，用于从自然语言任务与动作描述中自主合成形式化的符号动作模型（如 PDDL 规划域定义语言模型）。随后，利用经典自动化规划领域中具有严格正确性保证的成熟领域无关求解器（如 Fast Downward）来搜索并生成可证明有效的规划序列。

我们提出了一套创新的迭代提示流水线，能够自适应地提示 LLM 从高层动作描述中提取动作参数、前置条件与动作效果，并动态维护跨动作共享的谓词集合。在日常家庭服务机器人以及国际规划竞赛 IPC 基准域（Logistics、Tyreworld）上的严格实证评估表明：结合 GPT-4 提取的 PDDL 动作模型与经典规划求解器，任务规划成功率从纯 LLM 规划器的 15% 激增至 95%~100%，展现了利用大模型构建显式世界模型在自主智能体长程规划中的显著优势。

**【英文原文】**  
Large language models (LLMs) have demonstrated impressive common-sense reasoning and natural language capabilities. This has motivated significant interest in using LLMs directly for autonomous task planning. However, because LLMs lack an explicit, internal world model of causal state transitions, end-to-end LLM planners exhibit poor reliability and frequently produce physically invalid or hallucinated action sequences.

In this work, we advocate for a model-based planning paradigm: rather than using the LLM as the planning engine, we leverage pre-trained LLMs to construct explicit symbolic world models (expressed in PDDL). Once constructed, these models are fed into sound, domain-independent classical planners (e.g., Fast Downward) that guarantee correctness.

We present an interactive prompting pipeline that prompts LLMs to extract action parameters, preconditions, and effects from natural language action descriptions while actively maintaining a shared predicate vocabulary. Empirical evaluations on an everyday household-robot domain and IPC benchmarks (Logistics, Tyreworld) demonstrate that combining GPT-4 extracted PDDL models with classical planners dramatically elevates planning success from 15% (pure LLM) to 95%–100%, proving the efficacy of explicit world models.

### 1 引言与研究动机 / 1 Introduction & Motivation

**【中文精译】**  
智能体如何根据高级目标指令自主规划一系列有序的动作以达成期望状态，是人工智能领域的长期核心挑战。近年来，以 GPT-3/4 为代表的大语言模型在各类任务上展现了惊人的通用知识储备。大量学者尝试直接促使 LLM 生成具体规划步骤。然而，严格的基准评测揭示：当要求 LLM 独立充当端到端的黑盒规划器时，其成功率极低。LLM 极易产生幻觉、遗漏必要的前置准备步骤，或生成违反物理环境因果约束的无效动作序列。

规划能力的缺失根源于现代 LLM 本质上是基于词元概率分布的自回归序列预测器，缺乏对环境物理规律的内部显式“世界模型”。在经典自动化规划领域，智能体之所以能进行严谨推理，核心在于其依赖明确形式化的因果状态转移模型——定义了每个动作必须满足的前提条件（Preconditions）以及执行后触发的状态变更效果（Effects）。基于模型的规划求解器（如 Fast Downward）能够利用启发式搜索在庞大的状态空间中确定性地寻找有效路径。

然而，基于模型的规划范式长期面临着瓶颈：手工编写精确的符号领域模型（如 PDDL）需要耗费大量领域专家的脑力劳动与调试时间。为此，我们提出了一种两全其美的新方案：**利用预训练 LLM 作为知识提取器来构建显式世界模型，随后借助外部符号规划器生成可靠规划**（如图 1 所示）。

**【英文原文】**  
Autonomous task planning from high-level instructions is a foundational challenge in AI. While LLMs excel at language processing, recent benchmarks reveal that using LLMs directly as end-to-end planners yields poor results. LLMs suffer from hallucinations and fail to enforce causal physical constraints.

This failure stems from the lack of an explicit world model. In classical planning, agents rely on formal transition models that define action preconditions and effects. Model-based planners search systematically to guarantee correctness. However, manually authoring PDDL domain models is notoriously labor-intensive.

We propose a hybrid paradigm: **use LLMs as world model constructors, and employ domain-independent classical planners to generate provably correct plans** (Figure 1).

### 2 方法框架：从自然语言到 PDDL 世界模型 / 2 Methodology

**【中文精译】**  
规划域定义语言（PDDL）为表示世界模型提供了标准化的形式化载体。我们的方法包含以下核心阶段：

#### 2.1 提示工程与谓词动态维护
- **上下文注入**：向预训练大模型提供格式指南、来自不相干领域（如积木世界 Blocksworld）的格式示范、当前领域背景（如机器人物理结构与单臂限制）以及具体动作说明。
- **动作逐个迭代**：算法按顺序逐个提示生成每个动作的 PDDL 规范。
- **动态共享谓词表**：系统维护活跃谓词列表。当模型定义新谓词时，强制其提供自然语言描述并追加到列表中；后续动作强制优先复用已有谓词，消除符号冗余。
- **两阶段重新精炼**：在首轮获得全量谓词后，以完整谓词集作为全局上下文重新触发第二次生成，使先前动作能补全遗漏的隐式约束。

#### 2.2 双层纠错机制
1. **自动形式化验证器 (VAL)**：利用经典解析工具自动检查语法、未绑定变量及类型错误，将错误报告反向输入 LLM 触发自我纠错；
2. **人类专家极低开销定点审查**：基于自然语言解释，领域专家在数分钟内即可完成关键物理边界的终审确认。

#### 2.3 两种下游规划路线
- **路线 A（直接经典规划器）**：将生成的 PDDL 模型直接输入 Fast Downward 等求解器，保证 100% 形式化正确；
- **路线 B（VAL 引导的 LLM 规划）**：LLM 生成动作序列，PDDL 模型与 VAL 充当外部模拟器进行因果冲突检验与纠错回传。

**【英文原文】**  
PDDL provides a standardized representation for world models. Our methodology features:
1. **Prompting & Predicate Management**: Structured prompts guide the LLM to extract lifted PDDL actions one by one. A dynamic predicate dictionary ensures consistent vocabulary reuse across actions, followed by a second refinement pass.
2. **Dual-Layer Error Correction**: Automated PDDL syntax validation (VAL) provides feedback for model self-repair, followed by minimal human expert inspection.
3. **Downstream Planning**: Generated models are either solved directly via classical planners (Fast Downward) or used as world simulators to guide LLM search with VAL.

### 3 实验评测与结果分析 / 3 Experiments & Findings

**【中文精译】**  
我们在家庭日常机器人（Household，22 个复杂动作）以及国际规划竞赛基准（Logistics、Tyreworld）上展开评测：

#### 3.1 PDDL 动作模型合成质量（表 1）
- **GPT-4 表现极其出色**：在包含 22 个动作、271 个参数和字面量的 Household 域中，GPT-4 仅出现 53 处轻微瑕疵，而 GPT-3.5-Turbo 产生超过 218 处严重错误；在 Logistics 域仅出现 2 处瑕疵，在 Tyreworld 仅出现 4 处瑕疵。
- **专家人工修正成本微乎其微**：在拥有 22 个动作的复杂家庭机器人域中，专家修正仅耗时 15 分钟；Logistics 仅耗时 2 分钟；Tyreworld 仅耗时 4 分钟。相较于从头手工构建节省了 **超过 95% 的人力时间**。

#### 3.2 任务规划成功率（表 2）
- **纯 LLM 规划器 (Only LLM)**：Household 成功率仅 **15%**，Logistics 成功率 **0%**！
- **VAL 验证器反向提示 (LLM Modulo VAL)**：Household 提升至 **48%**，Logistics 提升至 **33%**，但常陷入局部死循环；
- **经典规划求解器 (Fast Downward + LLM PDDL)**：Household 成功率达到 **95%**，Logistics 达到 **100%**！

**【英文原文】**  
We evaluated on Household-robot (22 actions) and IPC domains (Logistics, Tyreworld):
- **Model Quality & Expert Cost (Table 1)**: GPT-4 produced highly accurate models (e.g., only 2 errors in Logistics, 4 in Tyreworld). Human correction required only 15 minutes for Household and 2–4 minutes for IPC domains (>95% time savings).
- **Planning Success (Table 2)**: Direct LLM planners achieved only 15% on Household and 0% on Logistics. In contrast, Fast Downward using LLM-constructed PDDL achieved **95% in Household and 100% in Logistics**.

### 4 核心启示与工程价值 / 4 Conclusion & Takeaways

**【中文精译】**  
该研究无可辩驳地证明了：**大模型绝不能被当作不可信的黑盒规划求解器直接使用；相反，应当充分发挥其常识提取优势，将其作为构建显式世界模型的上游工具，随后由外部确定性规则与求解器负责执行**。这一思想与 M3 PI Guard 中“让大模型提取参数意图、由权限编译器建立严格契约、由 Guard 实施确定性拦截”的架构体系完全契合。

**【英文原文】**  
This research proves that LLMs should not be deployed as unconstrained planning engines. Instead, leveraging LLMs to extract explicit, verifiable world models for deterministic external solvers bridges the gap between common-sense acquisition and rigorous execution correctness.
