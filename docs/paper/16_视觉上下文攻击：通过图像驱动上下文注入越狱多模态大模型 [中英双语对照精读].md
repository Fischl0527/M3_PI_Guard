## 1. 论文核心导读与执行摘要 (Executive Summary)

### 1.1 核心痛点与研究背景
- **传统多模态越狱（Vanilla MLLM Jailbreak）的本质局限**：
  现有的多模态大模型越狱攻击（如 FigStep、Typographic Attack、QR Attack 等）主要是将恶意文本问题直接渲染成图像（如排版文字图片、手写字体）或向安全图像注入对抗噪声。在这些方法中，**视觉模态本质上仅仅充当了规避文本安全分类器的“转译器”或“触发器”**。
- **两大致命缺陷**：
  1. **图文语义割裂（Semantic Disconnect）**：图像内容与伴随的文本提示词缺乏自然的逻辑依存关系（例如一张随意的风景图片搭配炸药制作问题），极易被新一代图文多模态安全护栏检测并拦截；
  2. **脱离真实物理情境（Lack of Physical Grounding）**：攻击无法利用图像中真实存在的物理环境和物体信息，无法形成符合现实常理的闭环诱导。

### 1.2 核心创新：以视觉为中心的越狱与 VisCo 攻击架构
1. **定义“以视觉为中心的越狱（Vision-Centric Jailbreak）”全新设定**：
   - 视觉信息不再仅仅是绕过滤网的旁路，而是构造**完整、逼真、具有不可替代上下文约束**的越狱情境的核心支柱。恶意意图必须与图像中的具体物体、场景深度绑定。
2. **VisCo 攻击框架的三阶段闭环流水线**：
   - **阶段一：以视觉为中心的对抗上下文生成（Vision-Centric Adversarial Context Generation）**：
     - 利用辅助多模态大模型提取图像的环境特征与实体描述 $D_I$；
     - 提出四大伪造情境注入策略：
       - **VS（Image-Grounded Scenario Simulation，基于图像的场景模拟）**：构建小说写作、剧本创作等虚构情境；
       - **VM（Image Multi-Perspective Analysis，图像多视角分析）**：引导模型从安全审查、防盗评估等专业视角解构场景；
       - **VI（Iterative Image Interrogation，迭代式图像问讯）**：通过伪造辩论与批判性多轮质询逐步瓦解模型防线；
       - **VH（Exploiting Image Hallucination，利用图像幻觉）**：结合多图拼接或新闻图表诱导跨模态认知偏差。
   - **阶段二：迭代式攻击提示词精炼（Iterative Attack Prompt Refinement）**：
     - **语义对齐评估（Semantic Assessment）**：确保攻击提示词与原始有害意图 $Q_h$ 严格对齐；
     - **毒性混淆与精炼（Toxicity Obfuscation & Refinement）**：将高敏感词汇替换为良性或中性隐喻，迭代优化直至通过内部毒性分类器。
   - **阶段三：黑盒攻击执行（Attack Execution）**：
     - 将伪造的多轮上下文序列与最终攻击提示词打包，向目标 MLLM 发起单轮或多轮黑盒交互，迫使模型输出极其详尽的高危操作指南。

### 1.3 核心实验结论与战绩
- **权威评测基准全线突破**：在 MM-SafetyBench、FigStep-SafeBench 和 HarmBench 三大主流多模态安全基准上，VisCo 在全部被测模型上均取得了统治级表现。
- **攻破主流最强多模态商业与开源旗舰**：
  - **GPT-4o**：攻击成功率（ASR）高达 **85.00%**，平均毒性评分达到 **4.78 / 5.0**；
  - **GPT-4o-mini**：ASR 达到 **86.13%**，毒性评分 **4.80**；
  - **Gemini-2.0-Flash**：ASR 高达 **91.07%**，毒性评分 **4.88**；
  - **InternVL2.5-78B**：ASR 达到 **90.18%**，毒性评分 **4.88**；
  - **LLaVA-OV-7B**：ASR 达到 **94.00%**。
- **大幅超越代表性基线**：相比于 Query-Relevant (QR) Attack 和 FigStep，VisCo 在 ASR 上实现了高达 50%~70% 的绝对提升，且毒性评分平均高出 2 个点以上。

### 第二节 相关工作 (2. Related Works)

- **针对 MLLM 的视觉越狱攻击**：
  早期工作主要利用连续对抗扰动（Adversarial Perturbations）直接攻击视觉编码器（如 CLIP 或 ViT），但此类方法对白盒梯度依赖极高，迁移到商业黑盒 API 时泛化能力极差。后续工作转向离散排版攻击（如 FigStep）或简单图文拼接（如 MM-SafetyBench 中的自然图像配对），但在安全分类器演进后均极易被识别。
- **情境学习与上下文越狱（In-Context Jailbreak, ICJ）**：
  在纯文本 LLM 中，利用历史对话中的良性或虚构样本欺骗自回归注意力已被广泛证明有效。然而，如何在多模态大模型中，将静态单张图像动态扩展为多轮逻辑自洽的图文对话历史，仍是此前未被攻克的空白领域。
- **多轮越狱攻击（Multi-turn Jailbreak）**：
  通过将有害意图拆解为渐进式多轮温和提问，逐步瓦解模型的安全防御。VisCo 创新性地在单轮调用中通过构造伪造历史对话（Fabricated Context），将多轮攻击的渐进诱导优势完美整合到 API 单次交互中。

### 第三节 方法设计：VisCo 攻击架构 (3. Methodology)

#### 3.1 问题形式化定义 (Problem Formulation)
- **输入要素**：目标多模态模型 $\mathcal{M}$、输入目标图像 $I$、有害意图查询 $Q_h$。
- **攻击载荷构造**：
  $$S_{atk} = (P_1, R_1, P_2, R_2, \dots, P_N, R_N, P_{atk})$$
  其中 $(P_1, R_1, \dots, P_N, R_N)$ 构成伪造的虚假对话历史 $C_{fake}$，$P_{atk}$ 为最终攻击提示词。模型推理过程为：
  $$R_{atk} = \mathcal{M}(I, S_{atk})$$
  攻击目标是使 $R_{atk}$ 在满足有害意图 $Q_h$ 的同时，最大化绕过安全分类器的概率。

#### 3.2 以视觉为中心的对抗上下文生成 (Context Generation)
1. **视觉实体与上下文特征提取**：
   使用辅助视觉语言模型 $\pi_{VLM}$ 提取目标图像的详细语义描述 $D_I$：
   $$D_I = \pi_{VLM}(I, Q_h, T_{des})$$
2. **四大伪造情境注入策略**：
   - **VS (Image-Grounded Scenario Simulation)**：构建虚构剧本或警匪小说创作背景，让模型以剧作顾问身份剖析场景；
   - **VM (Image Multi-Perspective Analysis)**：伪装为建筑安全审计师或保险风险评估专员，以“防范隐患”为由要求逐项分析薄弱点；
   - **VI (Iterative Image Interrogation)**：构造模拟质询，借由对图像中反常细节的追问，诱使模型逐步披露高危信息；
   - **VH (Exploiting Image Hallucination)**：利用跨模态注意力不一致性制造认知偏差，诱导模型产生安全幻觉。

#### 3.3 迭代式攻击提示词精炼 (Iterative Prompt Refinement)
- **语义对齐检测（Semantic Assessment）**：调用判别代理评估生成的改写提示词是否依旧能够精准达成原始恶意意图 $Q_h$，防止语义漂移导致攻击无效。
- **毒性混淆与精炼（Toxicity Obfuscation & Refinement）**：
  $$(P_{atk}^{(i)}) = \pi_{red}(Q_h, C'_{fake}, P_{atk}^{(i-1)}, Y_i, T_{refine})$$
  逐步剥离显式暴力与违法词汇，采用间接指代与技术隐喻重新封装，直至通过毒性过滤。

## 3. 防御建议与安全对齐启示 (Defensive Countermeasures)

1. **跨模态联合语义审查（Cross-Modal Joint Moderation）**：
   - 现有的安全护栏大多割裂地检测纯文本或纯图像。必须部署端到端的全模态实时护栏，跨模态比对图像实体与文本意图之间的关联，检测是否存在潜在的情境掩护犯罪。
2. **虚假上下文感知与会话完整性校验（Session Integrity Verification）**：
   - 针对在单次请求中伪造多轮交互的攻击手法，上层平台必须强制实施会话状态签名（Session HMAC），确保模型仅信任系统维护的真实历史，彻底阻断伪造对话注入。
3. **视觉为中心的拒绝微调（Vision-Centric Safety DPO/RLHF）**：
   - 在多模态大模型的后对齐训练中，主动引入“看似合法的专业咨询+危险真实图像”的困难对抗样本，强化模型对物理世界潜在危害的敏感度。
