# 运行手册：使用当前演示与跨环境指南

更新：2026-10-09。当前操作说明已并入[演示与跨环境运行指南](演示与跨环境运行指南.md)，统一维护安装、教师演示、119项限定检查、Ubuntu/Kali现成环境和结果目录。

日常演示无需再次安装依赖、重跑全部测试、启动Ollama或Docker，也不用模型API。

|想做什么|正确入口|
|---|---|
|生成后查看固定动作演示|[当前生成说明](演示与跨环境运行指南.md)；主工作区原页面在2026-10-10被本地标记删除，本轮不恢复|
|在本机生成临时演示|项目根目录执行`python -X utf8 -B -m scripts.portable_demo --output outputs/portability/demo-local-preview`，前提是当前解释器依赖齐全|
|在已安装的Ubuntu/Kali虚拟机演示|按[指南中的现成环境路径](演示与跨环境运行指南.md)，不复制原Windows环境|
|换新机器安装并验证|同一指南的“安装”和“怎样判断换环境成功”|
|找当前实验和评分记录|[证据索引](证据索引.md)、[项目目录指南](项目目录指南.md)|
|追溯旧比赛或paper-v1命令|[历史运行手册](archive/entry_snapshots_202607/运行手册.md)，仅作版本追溯，不直接照抄运行|

旧手册里的历史分析重建、Full Harness、盲测准入和批量模型命令不是日常检查步骤。生成数据、重建统计、调用模型都会改变文件或消耗资源，不能把名称带audit的命令一律当成只读操作。

本次整理没有执行上述命令，也没有重新验证所有历史实验入口。
