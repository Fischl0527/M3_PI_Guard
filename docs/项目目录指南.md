## 需要什么，就去哪里

| 要做的事情 | 目录 | 说明 |
|---|---|---|
| 了解项目、看报告和论文 | `docs/` | 只放供人阅读的文档和必要说明插图 |
| 修改模型交互、防护或评分 | `m3_core/`、`m3_guard/`、`m3_eval/`、`m3_attacks/` | 产品与算法源码 |
| 查看或运行某项实验 | `experiments/` | 实验实现；运行前另行确认研究范围 |
| 找实验方案和输入 | `protocols/`、`fixtures/`、`schemas/` | 协议、样本和数据格式；不是运行输出 |
| 找真实运行记录、统计表和图 | `outputs/` | 按研究名称查找，不从 docs 寻找数据 |
| 查当前进度和下一步 | `harness/state/` | current-task、progress、session-handoff |
| 查测试与通用构建工具 | `tests/`、`scripts/` | 测试、转换和构建代码 |
| 给老师演示、找换环境的验证结果 | `outputs/portability/` | 五个环境目录是实际运行结果；主工作区旧demo页面被本地标记删除，按运行指南另生成预览 |
| 拷贝限定可移植包到新机器 | `release/M3_PI_Guard_portable_20261009/` | 本地tar.gz与解包目录；不含密钥、模型或旧venv，不自动上传GitHub |
| 找历史交付工具包 | `release/archive/blind_custodian_toolkits/` | 七套历史包整包保留，已不属于活动盲测计划 |
| 找LaTeX模板与独立交付包 | `LaTeX通用模板/` | 原位置不变，目录整理没有修改模板或论文内容 |
| 找旧比赛材料 | `E:\M3_PI_Guard_archive\competition_history\M3_PI_Guard_test` | 比赛报告、原始附件、答辩、素材和发布包；仓库外保存，不上传当前GitHub |

根目录 `agent/` 是历史完整性审计材料，不是当前Harness状态目录。不要把产品源码或实验实现放进 `harness/`。

`outputs/portability/`的五个环境目录各有公开`verification.json`和本地`pytest.xml`。新包在目标机器生成的默认结果是包内`outputs/portability/verification.json`，收回主仓库时才按环境归档；不把五目录当作五套新模型研究。临时截图与下载的依赖包只留本地。
