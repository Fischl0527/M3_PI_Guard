## 新绘图

### N01 系统执行流程
![系统执行流程](<M3_01_系统执行流程.png>)
模型生成动作提案，Guard根据可信规则判断，执行层与评价层分别记录结果。虚线表示外部材料进入模型上下文，不自动获得授权。
数据来源：当前中文项目手册第3章；correctness_runtime_v1 / live_condition_runtime

### N02 v1至v4版本演进
![v1至v4版本演进](<M3_02_v1至v4版本演进.png>)
版本指corrected权限编译链。v1/v2重点修正动作资源与参数语义；v3/v4探索自然语言任务契约及动态对象授权。
数据来源：m3_core/policy_compiler_corrected_v1.py 至 policy_compiler_corrected_v4.py

### N03 论文主证据组成
![论文主证据组成](<M3_03_论文主证据组成.png>)
720+180构成900条授权研究；另有480条同期校准与16条合成控制。120校准案例嵌套于180案例；图中是执行组成，不是独立样本组成。
数据来源：manuscript_current_zh_v2.md 表1

### N04 DeepSeek Pro正常任务完成
![DeepSeek Pro正常任务完成](<M3_04_DeepSeek Pro正常任务完成.png>)
强化实证研究；AgentDojo 97任务；M3-v2 120任务。条形为已观察完成比例，横线为已有95% Wilson区间，标注为完成数/任务数。精确目标为离线目标对照。
数据来源：empirical_reinforcement_v1/analysis_v1.json cells / utility

### N05 V4.1 Flash正常任务完成
![V4.1 Flash正常任务完成](<M3_05_V4.1 Flash正常任务完成.png>)
强化实证研究；AgentDojo与M3-v2各60任务。条形为已观察完成比例，横线为已有95% Wilson区间，标注为完成数/任务数。精确目标为离线目标对照。
数据来源：empirical_reinforcement_v1/analysis_v1.json cells / utility

### N06 授权信息的配对效应
![授权信息的配对效应](<M3_06_授权信息的配对效应.png>)
同一底层任务的完成差异及现有95%配对Newcombe区间。Pro的两项AgentDojo主比较通过预定Holm校正；Flash用于方向复核。直接读取既有统计，没有重新抽样。
数据来源：empirical_reinforcement_v1/analysis_v1.json comparisons / utility

### N07 攻击活性与安全观察
![攻击活性与安全观察](<M3_07_攻击活性与安全观察.png>)
每条件计划40任务；比例和Wilson区间采用已知结果分母。无防护7/40，Policy/Full均0/40；对无防护的两项比较Holm后p=0.078125。VIGIL为指定适配配置。
数据来源：empirical_reinforcement_v1/analysis_v1.json cells / activity

### N08 确认负担与任务完成
![确认负担与任务完成](<M3_08_确认负担与任务完成.png>)
Pro/AgentDojo，97个正常任务。ASK计数表示执行中出现过等待确认的任务；它与完成状态分别统计，不能相加解释为互斥类别。
数据来源：empirical_reinforcement_v1/analysis_v1.json utility/pro/agentdojo-v1

### N09 受控机制检查
![受控机制检查](<M3_09_受控机制检查.png>)
每类20个越权提案；另20个合法提案在两配置下均放行。全研究40基础夹具、160提案对、320次判定，80对决定改变。这里是固定受控夹具的计数。
数据来源：empirical_reinforcement_v1/analysis_v1.json mechanism.controlled_cells

### N10 真实首提案回放
![真实首提案回放](<M3_10_真实首提案回放.png>)
457个可捕获条件项中获得358个首提案。Policy/Full有355对决定一致，3对由ASK变DENY；与受控夹具的判定变化分别解释。
数据来源：empirical_reinforcement_v1/analysis_v1.json mechanism.captured_decision_pairs

### N11 v3早期开发编译
![v3早期开发编译](<M3_11_v3早期开发编译.png>)
44次官方开发响应中4条编译通过、40条失败。来源分别为17/11/16任务；初始、v2、v3提示阶段分别记录，不把提示版本混作编译器版本。
数据来源：task_contract_compiler_v3_validation_v1/report.md 与 development_summary_v1.json

### N12 v3与v4编译状态
![v3与v4编译状态](<M3_12_v3与v4编译状态.png>)
同一32任务的开发比较，分调试16与资格16。v3最终5/32可运行，v4为0/32；图为编译最终状态，不是端到端任务完成率。
数据来源：task_contract_compiler_v4_development_v1/analysis_v1.json compilation

### N13 v4开发执行覆盖
![v4开发执行覆盖](<M3_13_v4开发执行覆盖.png>)
32任务×正常/攻击×五条件×两个执行模型。实际记录340项，Flash余300项明确未执行；任务记录包括编译失败/澄清等状态，不等于640次实际模型执行。
数据来源：task_contract_compiler_v4_development_v1/analysis_v1.json coverage；report.md

### N14 v1修复开发结果
![v1修复开发结果](<M3_14_v1修复开发结果.png>)
历史corrected-v1开发研究每模型48任务×六配置=288执行；本图取Pro/AgentDojo普通提示的8个良性与12个攻击任务，描述原始计数。
数据来源：manuscript_current_zh_v2.md corrected-v1开发研究段落；correctness_repair_v1/report.md

### N15 v2权限制度对照
![v2权限制度对照](<M3_15_v2权限制度对照.png>)
900条修正版授权研究的良性工具子集，每单元30任务。AgentDojo精确目标较自动权限提高完成，M3-v2未呈现同样方向；图为描述性计数，配对区间见正文。
数据来源：manuscript_current_zh_v2.md 表2
