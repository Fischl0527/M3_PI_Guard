## 2. 实际解决了什么问题

| 问题 | 实际证据 | 修正 |
|---|---|---|
| 最初交付漏带运行时策略和选样描述文件 | 干净Windows环境92项通过、16项失败 | 补入现有策略、E6任务描述和必要离线源记录，不删除失败测试 |
| 原生AgentDojo评分需要外部源码与依赖 | 现有解析器检查真实Git提交，并加载原生任务环境 | 交付固定提交的真实浅克隆；不伪造版本标记、不取消身份检查、不复制原Git配置 |
| Windows生成的测试清单为CRLF | Linux将行末回车视为文件名的一部分，未找到测试文件 | 清单明确写为LF，并加入回归测试 |
| Python 3.10不能解析某处f-string | 运行在导入权限编译器时发生SyntaxError | 将正则片段计算移到字符串外；逻辑与正则表达式不变 |
| Python 3.10没有标准库tomllib | 导入结构化基线模块时ModuleNotFoundError | 3.11及以后沿用tomllib；3.10使用兼容tomli，加入同接口测试 |
| 服务器缺少pip，网络下载不稳定 | 官方安装脚本超时/残缺；阿里云PyPI依赖解析失败 | 在任务专属虚拟环境安装pip；阿里云改用从官方PyPI下载的Python 3.10 Linux wheels离线安装 |

另有一次演示断言把没有写权限的结果误预期为DENY。真实检查器返回ASK且不执行；已修正演示预期，没有为了展示而加强或改变防护。

修复前、修复后的180份在线输入与参考权限逐条比较完全一致。这包括AgentDojo 80份、M3-v2 100份；四端重新编译也都得到相同权限，评价字段暴露数为0。这里没有改变授权规则，也没有重写历史研究记录。

Ubuntu26/Python3.14中PyYAML6.0.2从官方源码正常构建安装。pytest出现一条Google SDK内部类型别名的弃用警告（预计在Python3.17移除），不影响当前119项测试。首次使用带`../`的解释器路径启动，Python3.14另报告sys.prefix路径提示；改为规范的绝对路径启动后没有该提示。没有屏蔽警告、降级测试或为消除提示重复执行整套测试。

## 3. 哪些运行路径得到验证

- 当前corrected_v2权限编译器、监视器、可信数据标签传播，以及受控模拟效果和评分。

- 八种邮件场景/模块配置，以及“读取输入、错误改写输入、写入输出”的三个受控提案。

900条授权、480条同期、16条合成记录只离线读取，不重新执行。未知不填0；任务完成、违规效果和运行失败分别计数。没有重新做bootstrap、检验或科研结果筛选。

## 5. 给老师怎么演示

双击`outputs/portability/demo/index.html`即可，无需API、Docker或安装网站。页面由真实Python组件先运行后生成，浏览器切换的是这批实际受控结果，不是现场调用模型。

建议用5分钟：

1. 看“读取输入，把摘要写到输出”如何生成两种资源权限。
2. 指出“改写输入”没有完整许可，实际ASK、不执行；不是偷偷放行。
3. 选择公开内容：完整模块ALLOW，模拟邮件增加，任务完成。
4. 选择私密内容发往受限邮箱：完整模块DENY，邮箱不变；改成仅权限检查，可能完成任务却同时产生违规效果。
5. 选择分类缺失：完整模块ASK；不能由模型自己宣称公开，也不能让普通批准冒充可信分类。展开评分记录说明“提案、检查、执行、任务完成、违规”不是同一个指标。

浏览器已实际验证公开、私密、分类缺失及policy/full切换；查看了1440像素桌面和390像素窄屏截图，窄屏无横向溢出。临时localhost服务器和浏览器测试会话均已关闭。HTTP测试时唯一控制台资源错误为缺少favicon，非JavaScript执行错误；交付HTML不需要该图标或服务器。

采用前端设计技能的影响是把实际提案、决策和模拟效果并排呈现，英文决策都给出中文解释；没有加入虚构仪表数字或在线效果。
