# M3-PI Guard 文档索引

仓库内文档链接和命令示例默认相对仓库根目录书写。机器相关的解释器、模型、缓存和隔离环境路径只应出现在本地配置或明确标注的环境说明中；冻结证据内的历史绝对路径保持原样。

当前项目专用文档使用中文文件名和中文正文。标准入口 `README.md`、命令、schema、
JSON 字段、模型/方法名称和冻结协议标识保持原样，以避免破坏程序兼容性与证据身份。
活跃源码中的新增说明性注释优先使用中文；上游源码、公开接口和冻结文件不做批量翻译。
