## 中文阅读与原文保留

日常入口、解释说明和当前论文参考稿采用简体中文；技术英文附中文解释，文件名与接口字段保持不变。英文投稿正文及其源章节、参考文献原题名、原样冻结快照和旧外部审阅原文继续保留，不能因翻译改变证据。这些原文不是本轮承诺已全部译完的材料。旧 Word 保留历史用途；当前阅读以 Markdown 为准。

## 目录约定

`docs/` 只放供人阅读的文档、参考文献和必要说明插图。实验代码在 `experiments/`，方案与输入在 `protocols/`、`fixtures/`，结果在 `outputs/`，工程状态在 `harness/`。

Markdown 链接相对所在文档；命令未另作说明时从仓库根目录运行。历史冻结记录和归档原文中的绝对路径不批量改写。文档中的“计划”“执行”“验证”“可投稿”是不同状态，不能相互替代。
